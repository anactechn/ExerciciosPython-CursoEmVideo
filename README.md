# 📚 Exercícios Python - Curso em Vídeo (Mundo 3)

Este repositório contém uma coleção de exercícios resolvidos do **Curso de Python 3** do **Curso em Vídeo**, cobrindo principalmente os conceitos do Mundo 3 (Funções, Modularização e Tratamento de Erros).

## 🚀 Lista de Exercícios

### 🔢 Funções Básicas (96-100)
1. **Ex.96 - Área de Terreno Mágico**  
   Calcula área de terrenos com interface lúdica
2. **Ex.97 - Mensagem Mágica**  
   Formata textos com bordas adaptáveis
3. **Ex.98 - Contador Brincadeira**  
   Cria contagens personalizadas com animação
4. **Ex.99 - Super Detetive Numérico**  
   Identifica o maior número em uma lista
5. **Ex.100 - Sorteio Mágico**  
   Sorteia números e calcula soma dos pares

### 🗳️ Aplicações Práticas (101-106)
6. **Ex.101 - Verificador Eleitoral**  
   Checa situação de voto por idade
7. **Ex.102 - Calculadora Fatorial**  
   Calcula fatoriais com modo passo-a-passo
8. **Ex.103 - Ficha de Jogador**  
   Gera fichas com análise de desempenho
9. **Ex.104 - Validador de Números**  
   Input que só aceita valores inteiros
10. **Ex.105 - Analisador de Notas**  
    Estatísticas de turma com gráfico ASCII
11. **Ex.106 - Sistema de Ajuda**  
    Help() colorido e interativo
